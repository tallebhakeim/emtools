GPS — comment ça marche

trilatération, constellation, signal, relativité

Se positionner par les distances : la trilatération

Chaque satellite émet l'heure d'émission. Le récepteur mesure le temps de vol → une distance = c·Δt. Une distance le place sur un cercle (sphère en 3D) ; deux cercles → deux points ; trois lèvent l'ambiguïté en 2D. Mais l'horloge du récepteur est imprécise : ce biais d'horloge décale toutes les distances de la même quantité → une inconnue de plus. En 3D il faut donc 4 satellites (x, y, z + horloge).

ρ_i = ‖p − s_i‖ + c·b  (pseudo-distance)  →  4 inconnues (x, y, z, b) → 4 satellites

Le récepteur ne connaît PAS son horloge : il résout x, y et le biais d'horloge à partir des pseudo-distances (moindres carrés). Avec assez de satellites, la position trouvée (●) tombe sur la vraie (✕) et l'horloge est recalée — c'est pour ça qu'un GPS donne aussi l'heure très précisément.

La constellation et la géométrie (GDOP)

~31 satellites sur 6 plans orbitaux à 20 200 km (orbite moyenne, période ~11 h 58), pour qu'au moins 4 soient toujours visibles. La précision dépend de leur géométrie : des satellites bien étalés dans le ciel donnent un bon GDOP (faible) ; s'ils sont groupés, le GDOP explose (mauvaise précision). C'est la « dilution de précision ».

GDOP = √(trace[(HᵀH)⁻¹])   ·   erreur position ≈ GDOP × erreur de mesure (UERE)

Skyplot : le zénith est au centre, l'horizon au bord ; l'azimut fait le tour. Sous le masque d'élévation, un satellite est masqué (bâtiments, relief). PDOP/HDOP/VDOP = dilution sur la position 3D / horizontale / verticale.

Le signal : temps de vol et corrélation du code

Le satellite émet sur L1 = 1575,42 MHz (et L2, L5) un signal très faible (sous le bruit !) modulé par un code pseudo-aléatoire (PRN) propre à chaque satellite. Le récepteur génère le même code et le corrèle avec le signal reçu : le pic de corrélation donne le retard → la pseudo-distance. C'est l'étalement de spectre (CDMA) qui permet de tout extraire du bruit et de séparer les satellites.

Temps de vol

Code C/A : 1,023 Mchip/s, longueur 1023, se répète chaque ms ; 1 chip ≈ 293 m. Mesurer la phase du code à mieux que 1 % d'un chip → quelques mètres.

Autocorrélation du code PRN : pic étroit au bon décalage, ~0 ailleurs → mesure précise du retard

Relativité : pourquoi 38 µs/jour comptent

Deux effets relativistes décalent l'horloge embarquée. Relativité générale : plus haut = gravité plus faible → l'horloge du satellite avance (+45,7 µs/jour à 20 200 km). Relativité restreinte : le satellite va vite → son horloge retarde (−7,2 µs/jour). Net : +38,5 µs/jour. Non corrigé, ça décale la position de ~11 km/jour ! Les horloges sont pré-réglées pour compenser.

Δ_GR = (GM/c²)(1/R_T − 1/r)·t  ·  Δ_SR = −(v²/2c²)·t  ·  erreur ≈ c·Δ_net

À basse altitude (ISS) la vitesse domine → l'horloge retarde (net négatif). Vers 3 200 km les deux effets se compensent. Au-dessus (GPS, GEO) la gravité domine → l'horloge avance.
