Circuit — SPICE light

Un mini-simulateur de circuit dans le navigateur : décris un réseau R / L / C et sources, lance l'analyse fréquentielle (Bode) ou transitoire. Résolu par analyse nodale modifiée (MNA), comme SPICE.
Comment ça marche — écris une netlist (un composant par ligne, syntaxe façon SPICE), choisis un nœud de masse 0, puis lance l'analyse. En fréquentiel, la source AC sert d'entrée et on trace le diagramme de Bode (gain en dB + phase) de chaque nœud. En transitoire, on intègre la réponse temporelle (sources DC en échelon ou SIN). Le moteur résout le circuit par analyse nodale modifiée à chaque fréquence / pas de temps.
Circuit
EL211 – Électronique (IPSA Aéro 2, 2026-2027) : choisir un montage des TD 1 à 5. Il est chargé dans l'éditeur ci-dessous (modifiable), avec le point de repos affiché sur le schéma (mode « ⚡ Courants (DC) ») ou la simulation temporelle pour les montages en alternatif. Les diodes suivent le modèle du cours : seuil V0 + résistance dynamique Rd (idéale : 0 V, 0 Ω), Zener : Vz + Rz.
Clique un outil puis le quadrillage pour poser un composant (orientation via ⟳). Outil « Fil » : clic-clic entre deux points. Les bornes qui se touchent (ou reliées par un fil) forment un même nœud. Place une Masse = nœud 0. Double-clic / sélection pour éditer une valeur.
Aide-mémoire syntaxe
R1 a b 1k · C1 a b 100n · L1 a b 10m — résistance / condensateur / bobine entre nœuds a et b.
V1 in 0 AC 1 — source de tension (entrée fréquentielle, amplitude 1, phase optionnelle AC 1 90).
V1 in 0 DC 1 — échelon ; V1 in 0 SIN(0 1 1k) — sinus (offset, amplitude, fréquence) pour le transitoire.
I1 a b AC 1 — source de courant. K1 L1 L2 0.5 — couplage mutuel entre deux bobines (transfo / WPT ; M = k·√(L1·L2)). D1 a k — diode (anode a → cathode k ; Shockley, options Is n). O1 e+ e- s — AOP idéal (entrées e+/e-, sortie s).
S1 a b c d Ron Roff Vt Vh — interrupteur à hystérésis commandé en tension : fermé si V(c)−V(d) > Vt+Vh, ouvert si < Vt−Vh. W1 a b V1 gain Ron Roff Vt Vh — idem, commandé par gain·I(V1) (courant d'une source V, p. ex. de 0 V en sonde). Masse = nœud 0. Suffixes : f p n u m k meg g.
Chaîne de récupération d'énergie magnétoélectrique — échantillon Ni/LNO/Ni (circuit équivalent au port) → LTC3588-1 (modèle comportemental en clair, validé contre le modèle constructeur chiffré) → LED. Choisis un scénario : la simulation tourne dans le moteur MNA de la page et les courbes s'affichent dans le panneau Réponse ci-dessous.
Remèdes (sans alimentation externe) : ré-accorder la fréquence d'excitation en charge · mode rafale (gros réservoir + PGOOD) · redresseur actif / SSHI auto-alimenté par la sortie.
Schéma de la solution « rafales » : LED sur VOUT, commutée par PGOOD via un NMOS
